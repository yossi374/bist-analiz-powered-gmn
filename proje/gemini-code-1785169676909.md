# BIST Finansal Analiz Motoru (Yapay Zeka Destekli)

Bu proje, Borsa İstanbul (BIST) hisse senetlerini Yapı Kredi API'si üzerinden (15 dakika gecikmeli) çekerek, teknik ve temel analiz verilerini işleyen ve yapay zeka (Claude) kullanarak yatırımcılara stratejik kararlar (Al/Sat/Tut) sunan bir web uygulamasıdır.

## 📂 Proje Yapısı

Proje aşağıdaki modüler yapıya göre inşa edilmelidir:

*   `index.html`: Ana kullanıcı arayüzü.
*   `assets/css/style.css`: Stil dosyaları.
*   `assets/js/config.js`: API anahtarları, uç noktalar ve sabit ayarlar.
*   `assets/js/api.js`: Yapı Kredi API'si ile iletişim (OAuth2 token alımı ve veri çekimi) ve Claude API bağlantısı.
*   `assets/js/analysis.js`: Gelen ham fiyat/hacim verilerinden temel teknik indikatörlerin (RSI, Hareketli Ortalamalar, MACD) hesaplanması.
*   `assets/js/ui.js`: DOM manipülasyonları, sonuçların ekrana yazdırılması ve grafik çizimleri.
*   `assets/js/app.js`: Tüm modüllerin birleştirildiği ana başlatıcı dosya.

## 🔌 Veri Kaynağı: Yapı Kredi API

Sistem finansal verileri `https://api.yapikredi.com.tr/api/stockmarket/v1/` adresi üzerinden çekecektir. 
**Önemli Not:** BIST verileri 15 dakika gecikmelidir. Sistem, anlık "scalping" yerine, gün içi trend analizleri ve "swing trade" (dalga ticareti) kararları üzerine kurgulanacaktır.

Kullanılacak Uç Noktalar:
1.  `GET /bistIndices`: Endeks verileri için.
2.  `GET /stockInformation`: Belirli bir hissenin detaylı analizi için.

## 🧠 Yapay Zeka (Claude) İstek Mimarisi

Büyük Dil Modeli'ne (LLM) doğrudan ham veri gönderilmeyecektir. Önce `analysis.js` veriyi işleyecek, ardından aşağıdaki 3 Ajanlı Prompt Mimarisi çalıştırılacaktır. Uygulama bu promptları API üzerinden Claude'a iletecektir.

İncelenecek Hisse: {{HISSE_KODU}}
Tarih: {{TARIH}}

Veriler:
- Fiyat: {{FIYAT}}
