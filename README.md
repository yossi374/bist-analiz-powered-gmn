# 📈 BIST Finansal Analiz Motoru (Backend)

Yapay zeka desteğiyle Borsa İstanbul (BIST) hisselerini teknik indikatörler ve finansal veriler üzerinden analiz eden **FastAPI** tabanlı backend servisi.

---

## 🚀 Özellikler

* **🤖 Yapay Zeka Analizi:** Google Gemini API entegrasyonu ile hisse verilerini anlamlandırır ve Türkçe özet analiz sunar.
* **📊 Teknik İndikatörler:** Hareketli Ortalamalar (SMA), RSI ve MACD gibi temel göstergeleri işler.
* **⚡ Yüksek Performans:** FastAPI altyapısı sayesinde hızlı ve asenkron veri işleme.
* **☁️ Cloud Hazır:** Render ve Vercel gibi platformlarda sorunsuz dağıtım (deployment) mimarisi.

---

## 🛠️ Teknolojiler

* **Dil:** Python 3.10+
* **Framework:** FastAPI
* **AI Model:** Google Gemini API (`google-genai`)
* **Sunucu:** Uvicorn
* **Dağıtım (Hosting):** Render
